## ✨ What it is

Game Vault's console look on your iPhone: pick your games folder once and play N64, Nintendo DS, PSP, NES, Super Nintendo, Game Boy,
Game Boy Color, Game Boy Advance, PlayStation, Saturn, Genesis, Sega CD, 32X, Master System, Game Gear, arcade
(FinalBurn Neo), TurboGrafx-16 and CD, Neo Geo Pocket (Color), WonderSwan (Color), Atari 2600 / 5200 / 7800, Lynx,
ColecoVision, Virtual Boy, Pokémon mini and DOS games, with touch buttons or any controller. Your place is kept when you leave a game.

**Early test build.** Install the `.ipa` from Releases (or the latest build's artifact) with
[SideStore](https://sidestore.io) or [AltStore](https://altstore.io). With a free Apple ID the app must be refreshed
every 7 days.

Games: Files › On My iPhone › Game Vault › Games, or any folder you pick in the app (iCloud Drive, USB drive).

The emulators are libretro cores (FCEUmm, Snes9x, Gambatte, mGBA, PCSX ReARMed, Genesis Plus GX, PicoDrive,
Yabause, Beetle Saturn, FinalBurn Neo, Beetle PCE Fast, Beetle NeoPop, Beetle WonderSwan, Stella, a5200, ProSystem,
Handy, Gearcoleco, Beetle VB, PokeMini, DOSBox Pure, Mupen64Plus-Next, DeSmuME, PPSSPP), downloaded from the libretro build server when the app is built. Each is its own program
under its own licence; their source is at https://github.com/libretro.

## 🎮 The Game Vault family

Game Vault is one launcher plus emulators built to work with it. **Install [Game Vault](https://github.com/skitzellez/xbox-game-vault) and it sets these up for you**; press **RT** in Game Vault to update them all.

**Apps**

| Project | What it is | Runs on |
|---|---|---|
| [Game Vault](https://github.com/skitzellez/xbox-game-vault) | The launcher: plug in a USB drive, pick a game, play. Sets up everything below by itself. | Xbox Series X&#124;S |
| [Game Vault for Android](https://github.com/skitzellez/game-vault-android) | The same game library for phones, tablets and Android TV (beta). | Android |
| [**Game Vault for iPhone**](https://github.com/skitzellez/game-vault-ios) 📍 *you are here* | The Game Vault look on iPhone (early test). | iPhone |
